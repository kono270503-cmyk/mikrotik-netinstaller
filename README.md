# Графический инсталлятор MikroTik Netinstall-CLI

Этот скрипт позволяет легко прошить или восстановить оборудование MikroTik RouterBOARD в системах Linux без необходимости вводить сложные команды в терминале.

## Особенности
* Автоматически устанавливает графический движок `Zenity`.
* Сам скачивает официальную утилиту `netinstall-cli` от MikroTik.
* Позволяет выбрать сетевую карту и файл прошивки через удобные GUI окна.

## Быстрый запуск одной командой
Просто откройте терминал на любом Linux (Ubuntu, Debian, Fedora, Arch) и выполните:

```bash
curl -sSL https://githubusercontent.com | bash
```
